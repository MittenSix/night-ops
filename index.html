THE MISSION

Adventure begins with preparation.

Night Ops is an overnight, team-based outdoor challenge. Patrols practice navigation, communication, first aid, fire safety, teamwork, and outdoor skills so they can solve challenges calmly after dark.

Event times and exact competitions are set by each local Night Ops event, so check your troop’s current event packet. American Heritage Girls is a Christ-centered program that helps girls grow in faith, service, leadership, and a love for God while learning practical outdoor skills.
